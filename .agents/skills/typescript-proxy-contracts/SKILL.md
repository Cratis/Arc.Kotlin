# Change the generated proxy and TypeScript contract surface

This repository has no TypeScript **UI**, but it owns a generated TypeScript **contract
surface**: the proxies emitted by `:GradlePlugin` and the strict/runtime gates under
`ContractTests/TypeScript`. Any change to command/query metadata, the proxy renderer,
route options, or the servlet HTTP contract can move that surface, and three separate
gates will notice.

Invariants live in [`../../rules/typescript-proxies.md`](../../rules/typescript-proxies.md)
and [`../../rules/gradle.md`](../../rules/gradle.md). This file is the procedure.

## 1. Establish what generates the output

Read before editing, in this order:

- `CodeGeneration/KSP/src/main/kotlin/io/cratis/arc/codegeneration/ksp/ArcSymbolProcessor.kt`
  writes one format-7 artifact manifest per command/query compilation module to
  `META-INF/cratis/arc/<moduleName>.json` (`generateModule`), where `<moduleName>` is the
  required `arc.moduleName` KSP option. Source or indexed dependency handler declarations can
  affect response classification. The optional `arc.responseHandlerMetadata` option accepts an
  absolute file URI for a format-1 dependency handler index, separate from the artifact manifest.
  Handler-only compilations export supported public top-level source declarations under
  `META-INF/cratis/arc-response-handlers/` without an artifact manifest or module. Unindexed
  libraries remain undiscoverable, and runtime handler registration remains separate.
- `GradlePlugin/src/main/kotlin/io/cratis/arc/gradle/ArcManifestDiscovery.kt` discovers every
  manifest under the `META-INF/cratis/arc/` prefix on a classpath, rejects any
  `formatVersion` other than `ArcArtifactManifest.CURRENT_FORMAT_VERSION`, and merges
  descriptors in deterministic fully-qualified-name order.
- `GradlePlugin/src/main/kotlin/io/cratis/arc/gradle/TypeScriptProxyGenerator.kt` renders the
  proxies. It is the only writer of generated `.ts` files.
- `GradlePlugin/src/main/kotlin/io/cratis/arc/gradle/GenerateArcProxiesCli.kt` is the entry
  point used by the contract wiring and the samples; the published `io.cratis.arc` plugin
  registers the equivalent `generateArcProxies` task in
  `GradlePlugin/src/main/kotlin/io/cratis/arc/gradle/ArcGradlePlugin.kt`.

The contract generation arguments are fixed in `GradlePlugin/build.gradle.kts`
(`proxyArguments()`): `--route-prefix api`, `--route-segments-to-skip 5`,
`--proxy-segments-to-skip 5`, `--include-command-names true`, `--include-query-names true`,
`--enable-query-http-method true`, `--remove-stale-generated-files true`. Changing any of
them changes every generated route and path, so treat it as a contract change.

## 2. Know where the output lands

`ContractTests/TypeScript/generated/` is the contract output directory, and it is
**gitignored** (`.gitignore` line 5). There is no checked-in proxy snapshot to diff against
in git — capture a before-image yourself (step 5).

The checked-in `.NET`-derived comparison fixture is different: it lives at
`GradlePlugin/src/test/resources/differential/dotnet/**` and is compared inside
`:GradlePlugin:test`.

## 3. Make the change, then regenerate

```shell
./gradlew :GradlePlugin:generateContractTestProxies --no-configuration-cache
```

Every generated file starts with
`// @generated by Cratis. Source: <source>. Hash: <sha256>`. The generator refuses to
overwrite a file whose first line does not match that marker, and
`--remove-stale-generated-files true` deletes generated files that no longer have a source.

## 4. Determinism is a hard requirement

`:GradlePlugin:verifyContractTestProxyDeterminism` generates the contract proxies, hashes
every `.ts` file with SHA-256 in sorted relative-path order, regenerates, and re-hashes. A
mismatch fails with `Contract test TypeScript proxies changed between consecutive
generations.`

Non-determinism almost always comes from an unsorted collection, a map iteration order, a
timestamp, or a hash of a path that includes an absolute directory. Sort at the point of
emission — do not sort the file list afterwards to paper over it.

## 5. Inspect the generated diff

Because the output is gitignored, snapshot it around your change:

```shell
./gradlew :GradlePlugin:generateContractTestProxies --no-configuration-cache
cp -R ContractTests/TypeScript/generated .ai-work/proxies-before
# apply the change, then:
./gradlew :GradlePlugin:generateContractTestProxies --no-configuration-cache
diff -ru .ai-work/proxies-before ContractTests/TypeScript/generated
```

`.ai-work/` is the only allowed location for that scratch copy. Read the diff line by line:
an unexplained import, route, optionality, or `requiredRequestParameters` change is a
consumer-visible break even when every gate stays green.

## 6. Strict-mode compilation

```shell
./gradlew :ContractTests:typeScriptBuild --no-configuration-cache
```

This installs the locked dependencies with `npm ci --ignore-scripts`
(`:ContractTests:typeScriptInstall`), syncs the Kotlin and Chronicle sample proxies into
`ContractTests/TypeScript/generated/{runtime,chronicle}`, and runs `npm run build`
(`tsc --noEmit`).

`ContractTests/TypeScript/tsconfig.json` compiles with `strict`, `verbatimModuleSyntax`,
`moduleResolution: "Bundler"`, `experimentalDecorators`, `useDefineForClassFields: false`,
and `forceConsistentCasingInFileNames`, over `generated/**/*.ts` and `contracts/**/*.ts`.
`verbatimModuleSyntax` means a type-only dependency must be imported with `import type` or
`type` specifiers — getting that wrong fails the compile, not just lint.

Dependencies are pinned in `ContractTests/TypeScript/package.json`: `@cratis/arc` and
`@cratis/arc.react` 22.7.0, `@cratis/fundamentals` 7.18.2, `react` 18.3.1, `typescript`
5.9.3. If generated output needs a client rule or class the pinned runtime does not have,
that is a server-only boundary to document, not a proxy to emit.

## 7. Runtime TAP gate with exact totals

```shell
./gradlew :ContractTests:typeScriptRuntimeTest --no-configuration-cache
```

`ContractTests/TypeScript/contracts/run-runtime-gate.mjs` boots the executable
`Samples:Kotlin:SpringBoot` jar on `127.0.0.1` with `--server.port=0`, waits for the
`Tomcat started on port` line, probes `/.cratis/commands`, then runs three child test
processes and parses their TAP summaries:

| Child run | Time zone | Expected tests |
| --- | --- | --- |
| `contracts/runtime.calendar.contract.ts` | `UTC` | 5 |
| `contracts/runtime.calendar.contract.ts` | `America/Los_Angeles` | 5 |
| `contracts/runtime.contract.ts` | `UTC` | 15 |

`enforceTapSummary` requires `tests` and `pass` to equal the expected count exactly and
`fail`, `cancelled`, `skipped`, and `todo` to be `0`. Adding a runtime test therefore means
updating `expectedTests` in the same change; a skipped test is a failure, not a warning.

The gate also depends on `:ContractTests:typeScriptRuntimeHarnessTest`
(`node --test contracts/run-runtime-gate.test.mjs`), which has five unit tests covering the
TAP parser and the Spring spawn-failure path. `:ContractTests:check` depends on the runtime
gate, so `clean build` runs it unless it is excluded, as CI does.

## 8. The .NET-derived differential is a drift gate, not proof of parity

`:GradlePlugin:test` contains `raw jvm proxy bytes equal the prepared expected fixture`,
which compares sorted relative paths of all regular output files, then untouched JVM bytes
including headers against prepared `GradlePlugin/src/test/resources/differential/dotnet/**`
bytes. Only actual path separators change. The independent expected oracle validates 16 literal
source identities against fixture descriptors (queries use declaring models), reconstructs uppercase
SHA-256 headers from prepared expected bodies, and leaves three indexes headerless. It never reads
actual content or calls the production hash helper; a fixed `abc` vector guards hashing.

Read the complete rewrite inventory and source table in
`Documentation/guides/typescript-proxies.md`, "Expected-only differential preparation". It includes
expected LF/trailing-whitespace/terminal-newline preparation, FixtureModel quote/indent preparation,
CreateFixtures quote/import/request-array/class/hook formatting, exactly one enumerable generic
correction, the exact-site eslint/ts-ignore hook pair, and five literal type-only import patterns
(some no-ops on the current fixture). Only `Models/Observe.ts` also replaces the zero-space blank
line before its four-space-indented `filter: string;` member in exactly one known `ObserveParameters`
block with four spaces. This is not an empty interface; `ObserveOne.ts` is excluded. Missing/duplicate
anchors and misplaced suppressions fail preparation, and no type-soundness claim covers ignored
hook calls. Actual mutation tests exercise this same reader/preparer/byte comparator, including
wrong Observe spacing, non-TS files, headers, and a changed body with a valid recomputed hash.

Historical capture-time namespace/query casing and removed timestamps/hashes are embedded in the
fixture, not reproduced here. Capture SDK/tool versions remain unverified. `Contracts/Shape.ts`
is a class, not interface-emission proof. The Record fixture proves only string keys/string values,
not non-string keys, nullable entries, typed model values, `ValueMap`, or broader dictionary parity;
there is no Guid/DateOnly/TimeOnly fixture coverage. Overall parity remains Partial. Per
`Documentation/reference/parity.md`, ".NET-derived proxy differential gate", this "remains a
drift gate for the normalized fixture, not an exact raw .NET-output comparison; capture-time
fixture preparation is not yet reproducible tooling." Never describe a green differential as
raw .NET output equivalence.

## 9. Update the documented contract

If routes, methods, headers, envelopes, or statuses moved, update
`Documentation/reference/http-contract.md`. If generated shapes moved, update
`Documentation/guides/typescript-proxies.md`. If the public generator surface moved, update
`GradlePlugin/api/GradlePlugin.api` with an `apiDump` in the same commit.

## Verify

Run all of these, in order, from the repository root with a JDK 17 toolchain available:

```shell
./gradlew :GradlePlugin:test --no-configuration-cache
./gradlew :GradlePlugin:verifyContractTestProxyDeterminism --no-configuration-cache
./gradlew :ContractTests:typeScriptBuild --no-configuration-cache
./gradlew :ContractTests:typeScriptRuntimeTest --no-configuration-cache
./gradlew apiCheck
./Documentation/verify-markdown.sh
```

Done means: the differential and generator tests pass, two consecutive generations are
byte-identical, strict compilation succeeds, the runtime gate reports exact TAP totals with
zero fail/cancelled/skipped/todo, `.api` baselines match, documentation verification passes,
and you have read the generated diff from step 5 and can explain every changed line.
